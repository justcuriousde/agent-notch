# Security

Do not post credentials, private session transcripts, face images, or Keychain data in public issues.

If GitHub private vulnerability reporting is enabled, use Security → Report a vulnerability. Otherwise, open an issue requesting a private reporting channel without including exploit details or sensitive data.

AgentNotch reads local desktop-agent state. Provider format changes can affect detection. Optional webcam recognition is experimental and is not equivalent to Apple TrueDepth Face ID or operating-system authentication.

Only the latest source revision is actively maintained. Automatic updates are disabled.
